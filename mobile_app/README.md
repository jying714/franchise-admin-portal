# Doughboys Pizzeria Mobile App

Customer-facing Flutter app (Android + iOS) for the white-label franchise platform.

## Features
- Dynamic branding per franchise (colors, logo, name)
- Real-time menu with customization
- Cart, checkout, order history
- Favorites & Loyalty
- QR Scanner + Deep Linking
- Fully franchise-scoped data

## Development

```bash
cd mobile_app
flutter clean
flutter pub get
flutter gen-l10n
flutter run
